# 认知图谱建构原则

初始化图谱、扩展知识簇或实质修改节点与依赖时读取。本文件规定“什么样的认识值得成为节点，以及依赖为什么成立”；格式仍以 `learner-state-format.md` 为准。

## 理解是连接与压缩

两个人可能记得同样的命题，却拥有不同质量的知识：一个人保存许多孤立事实，另一个人能从少量核心认识重新推出这些事实。新系统追求后者。

- 连接的知识优于孤立事实。
- 可重新推导的依赖图优于章节清单。
- 理解优于复述。

好的图谱会让学习者产生“压缩”或“突然连起来”的感觉：信息没有减少，但任意事实不再需要单独记忆，而是由少数生成性认识支撑。

因此，节点和边都必须有解释力：节点是一个可验证认识，边说明该认识如何帮助生成后继认识。

## 无条件真理、公理与根节点

三个概念必须分开：

- **无条件真理**：在已经写明的范围内，学习者可以按字面、不带保留地接受的陈述。它描述陈述如何被持有。
- **公理**：在所采用的形式体系或解释框架中不从其他命题推出的起点。它描述逻辑地位。
- **根节点**：当前认知图谱中没有前置节点的节点。它描述图谱位置，并可能只是当前范围选择的结果。

它们可能重合，但不是同义词。一个可从更深层事实推出的陈述仍可能对学习者而言简单而无条件；一个根节点也可能带有适用条件，因而不是无条件真理。不要因为一句话听起来基础，就把它叫作公理。

### 寻找可靠基础

- 寻找少量能够不带保留接受的硬事实。数量很少没有问题；少而坚实优于多而摇晃。
- 若陈述需要“通常”“大多数时候”“忽略某些情况”等限定，它尚不是无条件真理。应写明条件、缩小范围，或继续向更基础认识追溯。
- 两种常见强形式是普遍陈述（“所有 X 都……”或“没有 X 会……”）和真正定义。但只在确实成立时使用，不强造。
- 普遍陈述中尤其有用的一种形式是识别领域的基本承载单位，例如“所有 X 都通过 Y 完成”。它能把许多表面不同的现象压到同一机制上；只有确实无例外时才采用，不能为了追求一句漂亮口号而绝对化。
- 真正定义说明一个概念是什么；一组常见属性、倾向或例子不能伪装成定义。
- 领域中不存在干净的无条件起点时，允许使用带明确适用条件的根节点。不要为追求整齐而制造绝对陈述。

### 根节点压力测试

对每个候选根节点逐项检查：

1. 这是当前范围内真正的起点，还是一个被教材直接宣布、但其实可推导的中层结论？
2. 是否存在更简单、学习者更容易按字面接受的陈述，可以自然推出它？
3. 它是否隐含未写明的适用条件、近似、争议框架或例外？
4. 权威来源是否支持该精确表述，而不只是支持一个更弱版本？
5. 初始筛查中，用户是否把它视为坚实，还是仍对其前提犹豫？

若它是伪装的中层结论，向下补足依赖；若只是因为当前使命裁剪而成为根节点，清楚保留适用条件，不称为公理。

## 依赖边是发现路径

边 `A → B` 不表示“教材先讲 A”“A 和 B 属于同一章”或“通常先学 A”。它表示：理解 A 是解释、发现或可靠推出 B 的必要认知支撑。

对每条候选边追问：

- 学习者如何用 A 走到 B？
- B 解决了什么由 A 暴露或尚未解决的问题？
- 若删除 A，B 是否会变成只能背诵的任意事实？
- A 是必要前置，还是仅仅有帮助的类比、例子或工具？后者不应写成必要前置。

从现实问题开始反向追踪：为什么需要目标认识；为了得到它，必须先看见什么问题；每个中间步骤为什么会成为合理的下一步。目标是让教学 Skill 日后能回答“我本来可以怎样发现它”，而不是把最终结论作为命令交给用户。

## 节点粒度

一个节点应包含一个能够独立验证的生成性认识。粒度合适时：

- 可以用一个核心因果机制概括。
- 可以给出明确的开放解释和迁移判据。
- 教学时能在一次对话中围绕它完成诊断、建立和验证。
- 它的前置能解释其主要机制，而不是只解释标题中的某个词。

如果节点需要多套互不相依的机制才能通过，通常应拆分；如果两个候选节点无法分别验证，且一个只是另一个的措辞变化，通常应合并。

## 调研与事实核验

构图前把问题拆成少量可核验方面：核心概念与定义、真正的第一原则、标准解释框架、常见误区，以及使命相关的适用边界。根据主题需要比较：

- 主教材对整体结构的处理。
- 官方文档、标准、原始数据或其他一手资料。
- 独立权威教材或同行评审资料对关键定义和依赖的核验。
- 时间敏感主题的最新权威信息。

权重原则：一手与官方来源优先于二手博客；直接回答当前结构问题的来源优先于泛泛材料；时效性会改变结论时，较新的可靠来源优先。发现资料空白或分歧时明确记录，不用自信措辞填补。

只有最终采用的来源进入 `RESOURCES.md`。搜索结果页、营销包装、重复转载和与使命无关的宽泛教程不作为结构依据。

## 提交前语义审计

除格式一致性外，再检查：

- 每个关键节点是否减少了孤立记忆，而不是新增一个必须背诵的标签。
- 每条边是否形成可讲授的动机链。
- 根节点是否足够坚实，且没有错误的绝对化。
- 最终目标是否确实可由主路径上的认识生成。
- 争议或条件是否写进节点，而非藏在来源中。
- Mermaid 只展示清单已有事实，没有用视觉布局暗示不存在的因果或优先级。
