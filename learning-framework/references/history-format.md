# 分簇学习证据与学习笔记

学习证据保存在学习工作区的 `nodes/C-xx-LEARNING.md`，每个知识簇一个文件。跨节点且长期有用的背景、结构事件及退役 ID 映射保存在 `nodes/NOTEBOOK.md`。普通选课只读 `LEARNER-STATE.md`；只在需要历史误解、既往证据或结构背景时检索相关片段。

## 分簇证据格式

```md
# C-01 学习证据：{知识簇名称}

## N-001｜{节点简称}

- S-YYYYMMDD-01｜节点结课｜{课中开放解释与新情境迁移；结课选择题的选项、理由及关键干扰项解释；结论}
- S-YYYYMMDD-02｜知识簇独立总测｜{新问题中实际证明或未通过的机制；判断理由；结论}
```

- 每个节点只在有事实时建立小节；不写“尚未验证”等占位条目。筛查、自述与单纯选择题命中不能冒充深层掌握证据，应标明性质。
- 新证据写入该节点所属知识簇文件；综合题证明多个簇的节点时，分别在各自簇文件记录同一课程序号和各节点的可观察证据。
- 一次状态变化在对应证据里写清结论即可，不另写内容相同的事件摘要。复测失败只记录经开放回答确认的节点；未定位的错误不能指派给具体节点。
- 只记录用户展示的关键推理、稳定或反复误解及纠正结果；不保存完整题目、答案或逐轮对话。已经纠正但有复习价值的误解可保留在该节点证据中。
- 当前掌握状态、最近验证、复测标志和当前稳定误解只以 `LEARNER-STATE.md` 为准。新节点通过须记录课中解释与迁移、结课严格选择题的推理；独立总测仅更新答案实际证明的旧节点。普通开课短问可验证旧节点，但不清除“到期：知识簇”。已掌握的历史节点不因新增结课规则追溯失效。

## 学习笔记格式

`nodes/NOTEBOOK.md` 是简短的跨节点笔记，不按课程序号记录流水账。只保留：使命背景中的重要选择、结构变化的原因与影响、退役 ID 的替代关系、跨多个簇的长期误解或复测判断。已有权威位置的节点陈述、判据、状态、证据和来源不在此复制。

结构事件可使用 `E-YYYYMMDD-NN`，记录日期、图谱版本、影响节点和简短原因；可由其指向分簇证据，但不重复证据叙述。结构迁移时总框架只处理受影响节点，未受影响证据不重写。

## 写入时机

教学 Skill 只有完成验证，或明确收尾且形成可复用诊断结论后才写分簇证据；中断中的半成品不落盘。总框架初始化或修改结构时写学习笔记；教学仅在出现跨节点、长期重要的新观察时追加。文件变长后可合并重复表述，但须保留会影响后续判断的证据与结构替代关系。
