# 节点定义：`nodes/N-xxx.md`

每个有效认知节点一个文件。只有选定当前节点后才读取其详情；前置节点仅在教学确实需要其判据、条件或材料时按需读取。文件名与一级标题 ID 必须和状态表“详情”列一致。

## 模板

```md
# N-008

- 陈述：用户能够解释……，并用它处理……的新问题。
- 稳定掌握判据：
  - 能解释核心机制。
  - 能连接必要前置。
  - 能处理变化条件。
  - 能迁移到表面不同的新问题。
- 关键来源：[R-001, R-002]
- 适用条件与争议：{适用条件、例外或权威分歧；没有则写“无”}
- 笔记：[notes/N-008.md]
- HTML：[assets/example.html]
- 材料复核：待复核：{原因}
```

“笔记”“HTML”“材料复核”是可选字段；没有内容时整行省略，不写空列表。所有材料路径相对于学习工作区根目录。一个节点文件只保存该节点的完整定义和材料链接，不重复简称、前置、类型、知识簇、状态、复测或历史证据。

## 字段所有权

- 总框架维护 ID、陈述、稳定掌握判据、关键来源、适用条件与争议；状态表中的简称也由总框架维护，必要的争议框架选择由用户确认。
- 教学 Skill 只维护笔记、HTML 与材料复核字段；不能借修改链接改变节点定义。
- 总框架发生结构变更时，只编辑受影响的节点文件，并将其既有材料标为待复核；不重写材料本体。被合并或删除的旧 ID 不复用，替代关系进入历史。
- 稳定掌握判据应让开放解释与新问题迁移可评分，也能据此构造无歧义的结课选择题。选项命中、材料覆盖或练习次数本身不构成掌握。

## 内容纪律

陈述是一个可独立验证的生成性认识。附带条件必须明确写出；争议来源的分歧不得被写成无条件真理。`MAP.md` 的标签来自状态表简称，地图不成为第二份节点定义。
