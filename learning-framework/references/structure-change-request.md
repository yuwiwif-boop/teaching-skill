# 图谱结构修改请求

教学 Skill 发现结构缺陷时，停止当前节点的深入教学，并在对话中输出以下内容。请求不单独保存为长期文件。

```md
## 图谱结构修改请求

- 当前结构版本：G-....
- 受影响节点：[N-...]
- 观察到的问题：{缺失前置／错误依赖／粒度不当／来源错误／内容错误／其他}
- 用户回答提供的证据：{只写支持判断的关键表现，不复制完整回答}
- 建议检查的方向：{需要核验的概念、依赖或来源；不是未经查证的最终修复}
- 可能影响主路线：是 | 否 | 不确定
- 当前教学处置：已停止该节点深入教学；未修改图谱结构；未更新该节点掌握状态
```

若问题会改变使命、主路线、范围或争议框架，总框架 Skill 必须先向用户展示影响并取得确认。局部结构修复仍须先查证，不能把教学 Skill 的建议直接当作事实。
