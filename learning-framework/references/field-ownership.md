# 字段所有权与冲突避免

每类字段只有一个权威位置。跨文件引用可以存在，字段值不能各维护一份。普通教学默认只读精简状态表；选定节点或触发复测后再按需打开其他文件。

| 文件与字段 | 学习总框架 | 认知节点教学 |
|---|---|---|
| `LEARNER-STATE.md` 使命、图谱版本、最终/阶段目标、簇目录、ID、简称、簇、前置、类型、详情路径 | 独占创建和结构修改；使命与主路线变更需用户确认 | 只读；结构问题提交修改请求 |
| `LEARNER-STATE.md` 状态、最近验证、复测、当前误解 | 初始化；结构变更时仅迁移受影响行 | 日常验证与复测后独占更新 |
| `nodes/N-xxx.md` ID、陈述、判据、关键来源、条件与争议 | 独占创建和修改 | 只读；发现错误时停止并交接 |
| `nodes/N-xxx.md` 笔记、HTML 与材料复核字段 | 结构变更时只标记受影响材料待复核 | 创建、复核、更新或废弃材料后维护 |
| `nodes/C-xx-LEARNING.md` 节点证据、复测失败与历史误解 | 结构迁移时只处理受影响记录；普通情况只读 | 明确收尾后按节点所属簇追加、审慎压缩 |
| `nodes/NOTEBOOK.md` 结构事件、退役 ID 替代关系和跨节点长期信息 | 独占结构事件；审慎压缩 | 仅追加跨节点且长期重要的教学观察 |
| `MAP.md` Mermaid 派生视图 | 按状态表中的简称与依赖维护受影响视图 | 只读；临时教学图留在对话 |
| `RESOURCES.md` 主教材和结构依据 | 独占维护；主教材变更需确认 | 只读 |
| `RESOURCES.md` 教学补充来源 | 可清理失效资源并留记录 | 仅在实际使用后追加 |
| `notes/`、`assets/` 内容 | 不重写；结构变更时标记对应节点材料待复核 | 按长期价值创建、复核、更新或废弃 |

## 结构迁移例外

总框架修改节点定义或依赖时可以调整受影响的教学字段：

- 未受影响行、节点文件及分簇证据保持原样。
- 新增、拆分、合并或内容被实质修改的节点设为“未掌握”；旧证据保留在原分簇记录，不冒充新节点的通过证据。
- 下游节点保留状态和最近验证，把复测标志设为“到期：关键前置”或更合适的现有类别；结构原因写入笔记。
- 只在受影响节点文件标记关联材料待复核。
- 一次结构提交无论修改多少节点，只递增一个图谱版本；纯教学状态变化不递增。

## 写入时机与一致性

教学 Skill 只有完成验证，或明确结束且形成可复用诊断结论后才集中写入。未收尾时，状态表、分簇证据、笔记、节点材料与资源都不写。总框架迁移旧格式可做一次性机械拆分；若未改变认知结构，不递增图谱版本。

提交前核对：状态表每个 ID 有一个同 ID 节点文件；节点定义无重复状态字段；最近验证 ID 在对应分簇证据中可找到；地图边等于状态表前置关系；来源 ID 可在资源表中找到。
