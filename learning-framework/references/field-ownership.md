# 字段所有权与冲突避免

“结构写入”和“教学写入”必须分离。除下表明确允许外，不修改另一 Skill 的字段。

| 材料/字段 | 学习总框架 | 认知节点教学 |
|---|---|---|
| 使命契约 | 创建；经用户确认后修改 | 只读；变化时请求总框架 |
| 图谱元数据、版本、阶段/最终目标 | 独占写入 | 只读 |
| Mermaid 视图 | 从节点清单重建 | 只读 |
| 节点 ID、陈述、簇、类型、前置、判据、关键来源、争议条件 | 独占写入 | 只读；发现问题时停止并请求修改 |
| 掌握状态、证据、误解、复测信息 | 初始化；结构变更时只迁移受影响数据 | 日常独占写入 |
| 笔记/HTML 链接与复核标记 | 结构变更时仅标记受影响材料“待复核” | 创建、复核、更新或废弃材料并维护链接 |
| 退役 ID 映射 | 独占写入 | 只读 |
| 事件记录 | 追加结构事件；可压缩历史 | 追加掌握、复测失败、重要误解事件 |
| 主教材、图谱结构依据 | 独占维护；主教材变更需确认 | 只读 |
| 教学补充来源 | 可清理失效项并保留失效记录 | 仅在实际使用后追加 |
| `notes/`、`assets/` 内容 | 不重写；结构变更时只标记待复核 | 按长期价值创建、复核、更新或废弃 |

## 结构迁移例外

总框架可以迁移受结构变化影响的教学字段，但必须遵守：

- 未受影响节点原样保留。
- 新增、拆分、合并或实质修改节点设为“未掌握”。旧证据可压缩保留在结构事件中，但不能冒充新节点的掌握证据。
- 下游节点保持状态，只把复测触发提前。
- 不确定如何迁移时，保留原始摘要并标为待复测，不猜测掌握。

## 提交粒度

一次明确收尾后集中写入相关字段，避免边问边写造成半完成状态。普通教学不递增结构版本；一次结构提交无论改多少节点，只递增一个版本。
