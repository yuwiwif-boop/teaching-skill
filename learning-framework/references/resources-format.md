# `RESOURCES.md` 规范

`RESOURCES.md` 位于学习工作区根目录，保存已确认主教材、图谱结构依据和教学中实际使用的补充来源。它不是待读清单。

## ID 规则

- 资源 ID 使用 `R-001` 起三位递增。
- ID 永不复用。新增前扫描当前最大编号并加一。
- 同一版本或同一网页只建一个条目；不同版本会影响内容时建立新 ID，并互相注明关系。

## 维护规则

- 总框架 Skill 维护主教材和结构依据，负责处理失效资源。主教材变更需要用户确认。
- 教学 Skill 只有在讲解、笔记或 HTML 中实际使用新来源时，才在“教学补充来源”追加条目。
- 教学 Skill 不得删除、替换或改写主教材和结构依据；发现问题时提交结构修改请求。
- 删除失效条目前，先把 ID、替代资源和原因移入“失效资源记录”，再更新受影响节点的来源引用。
- 每条来源必须说明用途和适用范围。优先一手资料、标准、同行评审研究、公认教材和权威机构；不得用搜索结果页充当来源。
- 争议内容同时记录相互冲突的权威来源及各自适用条件，不把其中一方写成无条件事实。
