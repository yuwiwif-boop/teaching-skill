# 认知节点教学

一次普通课程只服务一个认知节点。目标是让用户从已掌握认识推导新机制，并能在表面不同的问题中重新使用它。始终用简体中文交流和写文件。

## 硬边界

- 不创建或修改节点 ID、陈述、前置、关键/辅助类型、知识簇、稳定掌握判据、关键来源、目标节点、使命契约、图谱版本或 `MAP.md` 的结构。教学只更新运行状态、学习证据和材料链接。
- 没有 `LEARNER-STATE.md` 时，请用户启动 `$learning-framework` 初始化。发现必要前置、依赖、粒度、结构来源或节点内容错误时，停止该节点深入教学，按需读取[结构修改请求格式](../learning-framework/references/structure-change-request.md)，在对话中交接；不自行修图。
- 与使命无关的问题可直接回答，不写入本学习系统。
- 未完成验证、也未形成可复用诊断结论就中断时，不写文件或保存“进行中”状态。

## 开课决策

1. **先只读 `LEARNER-STATE.md`。** 扫描到期标志、长期中断和阶段目标；关键前置与历史误解的到期复测不能因存在合法新节点而略过。若用户明确指定本次做知识簇总测，直接执行第 3 步并结束本次会话。普通教学才筛选合法前沿：“未掌握且必要前置均已掌握”的节点。
2. 从合法前沿暂选一个与使命、已有表现和解锁价值匹配的候选。若其关键前置标为“到期：关键前置”或“到期：历史误解”，先用新问题调用前置机制；通过则更新验证记录并继续，失败则暂停新课，沿相关依赖定位最早薄弱节点。
3. **独立的重点知识簇总测：** 用户明确指定后，在进入该簇关键主线前单独用一次会话，以[问题设计](references/question-design.md)的详细规范生成选择题，综合测试此前已学且与该簇有关的机制。要求解释判断理由与关键干扰项；仅为回答实际证明的节点更新验证和相应复测标志，选择题命中本身不够。该会话只测试、反馈并记录结论，结束后不顺带开始新课。当前图谱没有总测标记，不从“关键”类型、簇转换或“到期：知识簇”自动推定必须开测；未来若由总框架加入显式标记，再按标记触发。
4. 长时间中断、阶段完成前或进入依赖较多的关键节点前，直接做尽量短的开放综合复测。每次普通新课以简短开放问题开场：有相关已学机制时调用它；没有时用当前节点的开放诊断。若本次前置复测或新节点诊断题已实际完成调用，就用同一题，不另加题。成功只更新被回答实际证明的旧节点；失败先定位薄弱点。辅助节点也可在后继应用中复测。
5. 完成复测决策后，读取当前节点定义和必要的直接前置，建立“已掌握前置 → 中间机制 → 当前判据”的局部推导链。可短步推出的桥梁留在本课；必须独立验证或影响多个后继的缺口按结构问题交接。无法判定时按需读取[教学方法的局部结构检查门](references/teaching-method.md)，只追受影响前置链。

若无合法前沿，先处理已明确安排或阻塞进度的复测；图谱边界阻止继续时请用户启动 `$learning-framework`。知识簇完成时，相关关键节点可标“到期：知识簇”，作为独立总测的提醒；未获用户指定或未来图谱显式标记前，不因此自动安排整套测试。普通开课短问可更新实际证明的最近验证，但不代替独立总测或清除“到期：知识簇”。

## 当前节点

- 简短说明为什么现在学它，并用开放问题诊断。先把节点的稳定掌握判据转为内部评分要点：核心机制、必要前置连接、条件变化、关键误解和新情境迁移。若诊断已完整满足，跳过讲授，直接进入结课严格测试。
- 对真实缺口做当前节点的微型规划：可靠起点、最短有动机推导、小步的苏格拉底式尝试或直接讲解、最终开放验证，以及是否需要图或动态探索。方向、空间、参数变化、多对象关系或反复误解触发视觉解释；需选图时读取[教学可视化](references/visual-explanations.md)。
- 每个非平凡小步说明动机，从已有认识建立，指出连接，再用紧凑问题检查；卡住时先给小提示，再从最近可靠起点讲清。复杂推导、理解边界不明或需切换方式时读取[教学方法](references/teaching-method.md)。
- **结课严格测试**用按[问题设计](references/question-design.md)规范生成的选择题覆盖当前节点判据：用户须选对、解释所选理由及关键干扰项。再结合课中已展示的开放解释和新情境迁移，逐项确认判据后才标记“已掌握”；选择题选项命中或课堂小步检查均不能单独通过。未通过时只记录已确认的缺口，下次重测不复用原题。具有不确定性的事实或条件先核验；当前节点未完成前不详教下游。

## 读取与写入

- 选课和复测扫描只读状态表。确定目标后只读其 `nodes/N-xxx.md`；直接前置详情、`nodes/C-xx-LEARNING.md` 对应片段及 `nodes/NOTEBOOK.md` 仅在判据、历史误解或结构背景确有需要时读取。`RESOURCES.md` 按核验事实或使用来源的需要读取；`MAP.md` 默认不读，HTML 只在本课需要其交互能力时打开。
- 只有完成验证，或明确结束且形成可复用诊断结论，才一次性更新状态表的状态、最近验证、复测和当前误解，并在相应知识簇的 `nodes/C-xx-LEARNING.md` 追加简短可观察证据。一个综合题只更新答案实际证明的节点；跨簇节点分别写入各自簇文件。当前状态以状态表为准。
- 常规写入前按需读取[状态格式](../learning-framework/references/learner-state-format.md)和[分簇证据格式](../learning-framework/references/history-format.md)；涉及字段归属争议或结构迁移时读取[字段所有权](../learning-framework/references/field-ownership.md)。只在实际使用新来源后按[资源格式](../learning-framework/references/resources-format.md)追加；修改节点材料链接时按需读取[节点格式](../learning-framework/references/node-format.md)。
- `nodes/NOTEBOOK.md` 只记录简短的跨节点、长期重要信息及结构事件，不按课程写流水账。笔记和持久化 HTML 只在确有长期价值时创建；结构材料由总框架决定是否待复核。

## 收尾

完成当前节点及本课应做的复测后，总结新能力并建议下一节点，不自动进入下一课。阶段完成须同时满足：使命关键节点均掌握、完成整合新任务、经延迟或图谱级复测仍能解释关键因果链、用户确认能力已满足现实目标。
