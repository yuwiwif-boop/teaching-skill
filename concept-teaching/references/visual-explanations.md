# 教学可视化决策

每次单节点微型规划都问：“这个机制是否需要被看见或动态探索？”这是必经判断，不表示每课必须生图。

## 主动触发

出现任一情形时，教学 Skill 主动提供图或交互表示，不等待用户要求：

- 涉及方向、旋转、投影、平移、翻转、重叠或空间关系。
- 改变参数会改变轨迹、形状、相位、支撑区间或系统行为。
- 多个对象、变量角色或依赖关系难以在一段文字中同时保持。
- 用户连续误判方向、变量角色或结构关系。
- 文字已反复解释而理解没有推进。

典型例子：复指数中 `σ` 改变包络、`ω` 改变旋转与投影，属于动态轨迹问题；卷积需要看见一个函数的翻转、平移、逐点乘积和重叠区域。若连续把时间平移方向说反，下一步切换到图和特征点检查。

## 分级输出

### 一级：临时图

优先选择能立即回答当前困惑的最轻形式：简洁 Mermaid、SVG 或代码绘图、ASCII 图，或当前环境可直接呈现的对话内交互 HTML。它只服务当前解释，不写入工作区，不修改 `MAP.md`，也不代替正式节点结构。

- 节点与关系用 Mermaid；精确位置、几何、方向、函数形状用坐标可控的 SVG 或绘图。
- 简单时用 ASCII 就足够，尤其在没有渲染或交互能力的环境。
- 环境不支持对话内交互 HTML 时，降级为静态图或 ASCII，并用几个选定参数状态描述变化；不要因此跳过已触发的视觉解释。
- 用户已经通过一个简单示意理解时，不升级成持久化素材。

### 二级：持久化 HTML

只有动态参数探索是核心学习方式、自动反馈显著改善练习，或材料对后续复习有长期价值，并且已完成实际渲染和交互检查时，才写入 `assets/`。在当前 `nodes/N-xxx.md` 维护链接。HTML 不保存学习状态。

## 不生图或暂缓

- 一句话或公式已完整说明机制，用户也能稳定解释并迁移。
- 图只是把文字换成形状，没有新增可见关系。
- 生图会打断很短、顺畅的推理链。
- 无法保证方向、比例、坐标或数值正确；先核验。若仍不能保证，明确用文字或可核验的最小 ASCII 示意完成教学，不能画错误图。

“拿不准要不要画”时检查主动触发条件；若条件成立，优先做正确的最小示意，不因制作成本放弃可视化。若没有条件命中，保持文字或公式。

## 一图一意与验证

先定唯一需要看见的认识，再删去可有可无的元素。通常超过约 5–7 个主要元素就应压缩或拆图。标签用短语，不塞段落。

渲染成功只证明语法可解析。持久化视觉材料必须经过“渲染 → 查看 → 修改”循环，检查箭头方向、依赖、坐标、角度、比例、标签、裁切、可读性以及实际交互。临时图也须核对关键语义；不能为填画面而编造数据、形状或边。

`MAP.md` 是状态表的派生地图。教学图可以放大局部机制，但不能新增正式依赖或写回地图。
